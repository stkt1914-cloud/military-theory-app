# 军事理论学习 App — 章节内容规范（子代理必读）

你是大学《军事理论》课程教材作者，为 iOS/Android 可用的**军事理论学习 App** 编写章节数据文件。
请严格按本规范输出，**只创建你自己负责的章节文件，绝不修改其他任何文件**。

## 内容合规要求（务必遵守）

1. 内容以**普通高校《军事理论》公共课公开教材体系**为蓝本，只写**公开常识性内容**（国防历史、公开的国防法规条款、公开的战略思想表述、公开的装备分类与概念）。
2. **不得**出现任何涉密/敏感内容：不写具体装备的涉密技术参数、不涉及军事机密信息、不发表政治敏感评论。
3. 立场积极正面：弘扬爱国主义、强调国防观念与强军思想，符合社会主义核心价值观。
4. 历史事实、法规条文（如《中华人民共和国国防法》《国防教育法》等公开条款）、领导人公开论述（如公开引用的毛泽东军事思想、习近平强军思想表述）务必准确。

## 你要创建的文件

一个章节一个 JS 文件，路径形如：`D:\deepseek harness\military-theory-app\data\chapter-XX.js`（XX 为两位数序号）。
文件必须是 **UTF-8 编码** 的纯 JavaScript，末尾加分号。

## 文件结构模板（必须完全遵循）

```js
// 章节：<章节标题>
window.CHAPTERS = window.CHAPTERS || {};
window.CHAPTERS['chapter-XX'] = {
  id: 'chapter-XX',
  order: 12,                    // 数字，与文件名序号一致
  icon: '🛡️',                   // 一个 emoji 图标
  title: '章节标题',
  summary: '一句话简介（1~2 句，用于列表页展示）',
  sections: [
    { type: 'text', html: '<h3>小节标题</h3><p>正文段落……</p>' },
    { type: 'code', title: '要点 / 流程标题', code: '……', note: '可选：说明' },
    { type: 'tip', kind: 'tip', html: '<p>小贴士</p>' },   // kind: 'tip' | 'info' | 'warn'
    { type: 'table', title: '可选表格标题', headers: ['列1', '列2'], rows: [['a', 'b'], ['c', 'd']] },
    { type: 'list', ordered: true, items: ['条目1', '条目2'] },
  ],
  exercises: [
    {
      id: 'chapter-XX-q1',
      type: 'choice',            // 'choice' 单选 | 'multiple' 多选 | 'code' 读材料单选 | 'fill' 填空
      question: '题干……',
      code: '可选：题目给出的材料/流程',
      options: ['选项A', '选项B', '选项C', '选项D'],
      answer: 1,                  // choice/code：正确下标；multiple：正确下标数组 [0,2]
      accept: ['答案'],           // fill 类型必填：可接受答案数组（忽略大小写与首尾空格）
      explanation: '详细解析，讲清为什么对、为什么错（40 字以上）。',
    },
  ],
};
```

## 硬性规则

1. **章节结构**：每章 `sections` 含 **6~10 个小节**：至少 3 个 `text`、至少 2 个 `code`（用"要点/流程/口诀"类结构化文本，如队列动作要领、射击步骤流程、按图行进步骤）、至少 1 个 `tip`，可用 `table`（对比表、时间表、条令要点表）与 `list`（小结要点）补充。
2. **练习题**：每章 **6~8 道**，题型多样（单选/多选/材料分析/填空），`answer` 下标必须真实正确；`explanation` 覆盖各选项错因；填空（fill）的 `accept` 尽量包含多种等价写法。
3. **`code` 块**：内容是"要点/流程/口令/步骤"文本（不是程序代码），用模板字符串（反引号）包裹；内部出现反引号或 `${` 需转义。
4. **HTML 内容**：`text`/`tip` 的 `html` 用双引号字符串包裹。可用标签：`<h3>` `<p>` `<b>` `<strong>` `<i>` `<em>` `<code>` `<sup>` `<sub>` `<ul>/<li>` `<ol>/<li>` `<br>` `<span>`。**不要**用 h1/h2/h4、img、table。
5. **中文内容**：全部简体中文，术语首次出现附英文（如：国防（national defense）、战略（strategy））。内容准确、严谨、通俗，面向大学生。
6. **不要**使用 require/import/export；只用模板里的写法。
7. 写完后用 `node --check` 检查语法，确保能被 Node 解析。

## 已分配的章节（只写你被分配的那些）

- 你的任务会明确列出要写的章节序号与标题清单。只创建清单中的文件，每章一个文件，内容不与其他章重复。

## 质量要求

- 内容像一本规范的军事理论教材：概念/背景 → 核心内容 → 要点归纳 → 易错/注意 → 小结。
- 练习题有区分度：1~2 道送分题（概念），2~3 道中等题（常识/理解），1~2 道易错题（易混淆概念，如国防类型、战略格局、军兵种职责等）。
- 每道题 `explanation` 覆盖所有选项错因。
